# SXM · 呼吸之间

一场 33 秒的拾光小游戏。按住吸气，松开呼气，让圆环经过漂浮的光点。

在线体验：[https://sxm6688.github.io/sxm-breath/](https://sxm6688.github.io/sxm-breath/)

## 玩法

- 按住屏幕或鼠标：吸气，圆环扩张。
- 松开：呼气，圆环收回。
- 让圆环经过光点即可拾取，避开土色菱形的杂念。
- 三轮呼吸后查看共振指数、拾光数量与最高连击。

## 技术

纯 HTML / CSS / JavaScript，Canvas 绘制，无外部依赖，适配手机与桌面。
